# Good Code Review

A reference for what to check when reviewing code, for people and agents.

**Reviewing a change?** Start with `cards/change/`. **Auditing code that already exists?** Pick a level in `cards/audit/`.
Every check ends in `PASS`, `FAIL` or `N/A` with `file:line` evidence, and each `FAIL` carries a severity: `block`, `should-fix` or `discuss`.
