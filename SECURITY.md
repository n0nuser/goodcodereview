# Security policy

## Report a vulnerability

Use GitHub private vulnerability reporting: open the **Security** tab of [n0nuser/goodcodereview](https://github.com/n0nuser/goodcodereview) and choose **Report a vulnerability**. Do not open a public issue for a vulnerability.

## Scope

In scope:

- The Python tools in `tools/` (`validate.py`, `build.py`).
- The workflow in `.github/workflows/`.
- The site build and its output, such as injected markup in generated pages.

Out of scope:

- Disagreement with a card's advice. Open a [card correction](https://github.com/n0nuser/goodcodereview/issues/new?template=card-correction.yml) instead.
- Vulnerabilities in third-party tools that the cards mention.

## Supported versions

Only the `main` branch is supported.
