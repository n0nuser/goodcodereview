# Company sweep: Uber, Stripe, Spotify, Cabify

Read 2026-10-25 by fetching each page with curl and searching its text. Haiku workers found the candidate posts. Every row below was checked against the page text, and each quote was seen on the page. Paraphrase only. Each row gives the URL, org, year, the point, and the card clause it backs.

## Rows that back a Rule clause

1. https://engineering.atspotify.com/2026/9/portal-by-spotify-cut-my-claude-code-token-usage-by-90. Spotify, 2026. Routing rules in `CLAUDE.md` were moved into Claude Code hooks because the model could skip written rules. Quote: "The rules were advisory, not enforced. Claude could ignore them." Backs `code-rule-has-enforcer`, Rule.
2. https://engineering.atspotify.com/2026/6/code-with-claude-coding-is-no-longer-the-constraint. Spotify, 2026. Standards for each component type ("golden state") are backed by static analysis and lint, so an agent gets feedback when it uses the wrong pattern. Spotify standardises on a small set of technologies, and Soundcheck lets teams check components against the standard. Backs `code-rule-has-enforcer`, Rule (lint over prose), and `code-consistency-drift`, Rule (one standard). The Soundcheck part backs the tracking sentence in that card's Why.
3. https://stripe.dev/blog/formatting-an-entire-25-million-line-codebase-overnight-the-rubyfmt-story. Stripe, 2026. An autoformatter with no configuration replaced format comments in code review. Quote: "I sometimes receive code format nits on code reviews." Backs `code-rule-has-enforcer`, Rule.
4. https://stripe.dev/blog/sorbet-stripes-type-checker-for-ruby. Stripe, 2022. Sorbet type checking became a required step in the automated test suite. A CI comment on each pull request scores the change, counting files that are not strictly typed. Backs `code-rule-has-enforcer`, Rule, and the tracking sentence in `code-consistency-drift`'s Why.
5. https://tech.cabify.com/blog/engineering/cabify-container-certification. Cabify, 2025. Teams each scanned images their own way, or not at all, and manual reviews could not keep up. Image certification is now enforced at build and deploy. Quote: "developers cannot bypass it." Backs `code-rule-has-enforcer`, Rule, and `code-consistency-drift`, Rule (one way per concern).
6. https://www.uber.com/blog/designing-mcp-gateway/. Uber, 2026. A crawler derives MCP tools and their schemas from the Protobuf and Thrift IDL registry, so teams do not write MCP servers by hand. Quote: "derives MCP servers and tools directly from the IDL Registry." Backs `mod-derive-dont-duplicate`, Rule.
7. https://www.uber.com/blog/high-performance-grpc/. Uber, 2026. A pipeline generates OpenSearch's Protobuf API from the REST JSON spec, to avoid manual drift between the two. It also checks new protos against previously generated ones, so older clients keep working. Backs `mod-derive-dont-duplicate`, Rule. It does not back `chg-proto-no-field-type-change`: it names field renumbering, not a type change.
8. https://stripe.dev/blog/how-api-changes-flow-into-stripes-developer-products. Stripe, 2026. Two API formats meant SDK and reference generators were duplicated. Stripe converged on OpenAPI, generated from its API DSL, and tests validate API changes before merge, including backwards compatibility. Backs `mod-derive-dont-duplicate`, Rule, and `svc-api-spec-matches-impl`, both clauses ("generate it from the code").
9. https://stripe.dev/blog/shepherd-how-stripe-adapted-chronon-to-scale-ml-feature-development. Stripe, 2024. Engineers define each ML feature once, and the same definition computes online and offline features. Backs `mod-derive-dont-duplicate`, Rule. Same org as row 8.
10. https://engineering.atspotify.com/2026/5/spotify-ads-api-claude-plugins. Spotify, 2026. The plugin ships the published OpenAPI spec instead of translating it into MCP tool schemas and maintaining that copy. Quote: "The OpenAPI spec is the source of truth." Backs `mod-derive-dont-duplicate`, Rule, and `svc-api-spec-matches-impl`, source-of-truth clause only.
11. https://tech.cabify.com/blog/engineering/shadow-routing-providers. Cabify, 2025. Shadow requests run in the background behind a worker pool, and a request is skipped when no worker is free. Quote: "a worker pool that limits how many shadow requests can run concurrently." Backs `svc-bounded-background-tasks`, Rule.
12. https://stripe.dev/blog/minions-stripes-one-shot-end-to-end-coding-agents. Stripe, 2026. More than a thousand agent-written pull requests merge each week. People review each one, and the engineer asks another engineer to review it. Quote: "while they're human-reviewed, they contain no human-written code." Backs `chg-agent-independent-review`, the person half of the Rule only.
13. https://www.uber.com/blog/efficient-software-factory/. Uber, 2026. Managed agents handle code maintenance tasks with human reviews and escalations. Quote: "code maintenance tasks with human reviews/escalations." Backs `chg-agent-independent-review`, the person half of the Rule, and only for maintenance tasks.
14. https://stripe.dev/blog/migrating-to-typescript. Stripe, 2022. Stripe moved 3.7 million lines from Flow to TypeScript in one pull request, so that engineers would not work in both type systems. Quote: "In a single pull request, we converted more than 3.7 million lines." Backs `chg-delete-legacy-after-migration`, Rule.
15. https://www.uber.com/blog/high-throughput-processing/. Uber, 2026. Several processors compete for one batch, and an atomic update with optimistic locking gives exactly-once processing. Quote: "an atomic update with optimistic locking ensures exactly-once processing." Backs `fn-rerun-safe-after-crash`, rerun clause only.
16. https://stripe.dev/blog/how-stripe-uses-graph-search-and-state-machines-to-auto-remediate-a-global-database-fleet. Stripe, 2026. A cancelled remediation used to leave shards in states no plugin handled. Now each run computes its path from the shard's current state, and Temporal resumes interrupted workflows. Backs `fn-rerun-safe-after-crash`, rerun and crash clauses (derive each step from current state).
17. https://www.uber.com/blog/ubers-rate-limiting-system/. Uber, 2026. Teams each built their own throttling, which gave inconsistent behaviour for the same quota. One rate-limit service replaced them, and owners configure limits per caller without code changes. Backs `code-consistency-drift`, Rule, and `mod-central-config`, "no knobs in code" only.
18. https://tech.cabify.com/blog/engineering/hubs-experience. Cabify, 2025. Hardcoded pickup instructions meant every change needed engineering work and a deploy, so the knobs moved into an admin tool. Backs `mod-central-config`, "no knobs in code" only.

## Rows from source pass 6, re-checked

- https://learn.microsoft.com/en-us/aspnet/core/security/authentication/identity-configuration: confirmed. The defaults are 5 failed attempts and a 5-minute lockout, and a successful sign-in resets the count. The sample passes `lockoutOnFailure: false`.
- https://auth0.com/docs/secure/attack-protection/brute-force-protection: confirmed. The threshold counts attempts from one IP to one user identifier (default 10, range 1 to 100). Account Lockout is off by default.
- https://docs.cloud.google.com/identity-platform/docs/admin/email-enumeration-protection: confirmed. Invalid sign-in returns one `INVALID_LOGIN_CREDENTIALS` error, and password reset gives no sign of whether the address exists. Sign-up still returns `EMAIL_EXISTS`. Nothing on timing.
- https://www.stepsecurity.io/blog/pinning-github-actions-for-enhanced-security-a-complete-guide: confirmed. It argues for full commit SHA pins from its own attack scenario, without citing GitHub's page.
- https://www.nist.gov/itl/executive-order-14028-improving-nations-cybersecurity/software-security-supply-chains-software-1: confirmed. Quote: "Require software producers to maintain readily accessible and digitally signed SBOM repositories." The page is written for federal buyers and does not name CI.
- https://cheatsheetseries.owasp.org/cheatsheets/Authentication_Cheat_Sheet.html, re-checked for the status clause: a different HTTP response code "can leak information about whether the account is valid or not."
