# Test fixtures built once: sources

Fetched 2026-11-05 through WebFetch (a small model summarises the page), so every row is paraphrase. Each row gives the URL, the org, what it says, and the card whose Rule it backs.

1. https://docs.pytest.org/en/stable/how-to/fixtures.html (org: pytest). Scopes are `function` (default), `class`, `module`, `package`, `session`; a fixture is created when first requested and destroyed per its scope. A fixture may use a broader-scoped one, not the reverse. Fixtures needing network access "are usually time-expensive to create"; a module-scoped `smtp_connection` is shared so "the two test functions ... run as quick as a single one". Dynamic scope (5.2+) is "especially useful when dealing with fixtures that need time for setup, like spawning a docker container". Yield teardown runs in reverse order; pytest caches one instance at a time. Backs `py-test-fixtures-built-once`.
2. https://docs.python.org/3/library/unittest.html (org: Python Software Foundation). `setUpClass`/`setUpModule` build state once per class or module, with `cls._connection = createExpensiveConnectionObject()` as the example. "Shared fixtures do not play well with [potential] features like test parallelization and they break test isolation. They should be used with care." A randomised order can call them more than once. A failing `setUpClass` skips the class and `tearDownClass`; `addClassCleanup`/`addModuleCleanup` still run. 3.12 adds `--durations N`. Backs `py-test-fixtures-built-once`, and is the source of its counterpoint.
3. https://github.com/zupo/awesome-pytest-speedup (person: zupo, a reference). "Measure first!"; `pytest --durations 10`; prepare the database once and either `TRUNCATE` tables or run each test in a transaction that is rolled back (tests must not commit); xdist runs session fixtures on every worker, so use a database per worker; block network with `pytest-socket`, fake disk with `pyfakefs`; `pytest-skip-slow` for `@pytest.mark.slow`. A person's list: counts for no org. Backs the reset clause of `py-test-fixtures-built-once`.

Also read, no rule: https://docs.pytest.org/en/stable/explanation/goodpractices.html (nothing on test speed), https://docs.pytest.org/en/stable/how-to/usage.html (`--durations=10 --durations-min=1.0`; durations under 0.005s hidden without `-vv`).

Count: pytest and PSF back the Python scope mechanics. The language-neutral and database claims are counted in `test-fixtures-orgs-A.md` (12 orgs build once, 10 orgs reset per test).
