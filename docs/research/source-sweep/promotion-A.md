- svc-bound-inbound-concurrency: PROMOTED, severity should-fix, no Rule edit. Orgs (one clause, all four state it): aws, tokio, uber, netflix. AWS: overall concurrency limit, reject new work, and timeouts/retries alone do not prevent running out of concurrency. Netflix: in-flight gauge, requests rejected once it equals the limit. Uber: in-flight concurrency as the overload signal, static inflight limits. Tokio: "limit the number of incoming requests being handled at the same time". Linked cards (svc-circuit-breaker-bulkhead, svc-bounded-background-tasks, sys-load-shedding-bounded-queues) are stable; no stable duplicate (the bulkhead card is per-dependency).

The split advice moved to the Why; Counterpoint now lets a flat dispatch pass with a note.
